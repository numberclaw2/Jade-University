# Jade University v0.2 — Curriculum Architecture

- Replaced the initial standalone curriculum concept with an Alfred-derived source map.
- Established the governing rule: reuse Alfred first; trim/resequence before creating new teaching.
- Defined 8 Jade priority blocks.
- Defined Priorities 1–5 as the Apply-Now Core.
- Defined Priorities 6–8 as the Embedded-Hardware Bridge.
- Mapped each Jade priority to existing Alfred source weeks, career-section IDs, media, labs, and evidence requirements.
- Explicitly deferred lower-priority Alfred breadth so it does not slow the technician transition.
- Preserved Alfred as the comprehensive CETa/electronics-to-embedded course.
