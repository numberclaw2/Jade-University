# Jade University v0.4.0 — Learning-Parity Acceptance Report

This release addresses the v0.3 learning-parity audit without expanding Jade back into Alfred’s full curriculum.

## Implemented parity targets
- **64/64** teaching sections have a concrete worked technician model (`Jade models it`), retrieval prompt, guided application, and changed-context practice.
- **64/64** sections have an assigned first-pass **Video + Written** resource pair.
- **16/16** lessons have a constructed explain-back evidence prompt in addition to MCQs and practical evidence.
- Study enforces a **reached-only** boundary and exposes Review / Flashcards / Watch & Review / Reference / Weak Areas / Active Recall.
- Active Recall and vocabulary retrieval use Again / Hard / Got it scheduling with progressive review intervals; those records remain separate from official course mastery.
- Question review supports exact **Question → Teaching → Back to Question** routing and preserves the return route through lesson re-renders.
- Practice routes required work to the exact first gap and also surfaces due section-level retrieval review.
- Practical routes distinguish **PHYSICAL REQUIRED**, **PHYSICAL PREFERRED / SIMULATION ALLOWED**, and **SIMULATION ACCEPTABLE** work.
- Real, attributed, non-AI instructional figures are integrated where they materially improve comprehension.
- Vocabulary retrieval reuses the existing glossary source of truth rather than creating a second vocabulary bank.

## Executed validation
- Curriculum: **8 blocks / 16 lessons / 64 sections**.
- Enhancement coverage: **64/64 section records**, zero missing.
- Worked-model coverage: **64/64**, zero missing.
- Lesson enhancement coverage: **16/16**, zero missing.
- Resource library: **38 linked resources**.
- First-pass resource-pair validation: **64/64 contain at least one Video and one Written resource**, zero missing IDs and zero bad pairs.
- Glossary: **96 terms** retained as the technician-scope source of truth.
- Instructional figures: **10 real-source figure records**, used contextually in **17** section placements; all figure references resolve.
- Static HTML: **0 duplicate IDs** and **0 missing local `href`/`src` references**.
- Script inclusion: all main pages load `learning-enhancements.js`.
- JavaScript syntax: PASS for `app.js`, `curriculum.js`, `resources-data.js`, `glossary-data.js`, `learning-enhancements.js`, and `service-worker.js`.

## Validation boundary
A full native-browser interaction harness is not available in this execution environment, so this report does not claim rendered-browser acceptance. Post-upload verification should still confirm the six Study modes, exact question-return routing, one practical route, and mobile layout on the deployed GitHub Pages origin.

## Scope intentionally unchanged
No calendar, CETa exam engine, broad RF, full C/Python course, cloud sync, or Alfred-style administrative systems were added. Learning-quality parity is the target; Alfred’s size is not.
