# Jade Curriculum Import Checklist

Use this checklist when converting the source map into live Jade lesson content.

## Rule
Copy/adapt the strongest existing Alfred teaching first. Do not paraphrase an Alfred section into a second independent lesson unless the Jade flow genuinely requires a shorter bridge.

## Per-module import steps
1. Pull the listed Alfred source week(s) and career-section IDs.
2. Keep the original ground-up teaching and worked examples where they fit.
3. Remove only material explicitly listed as deferred.
4. Preserve glossary terms and first-occurrence behavior.
5. Carry over the strongest existing required video + written literature resources.
6. Carry over existing real diagrams/figures when instructionally relevant.
7. Keep hands-on exercises that produce technician evidence.
8. Add a Jade transition paragraph only when resequencing creates a prerequisite gap.
9. Verify no concept is assumed before it is taught in Jade.
10. Record provenance in the lesson metadata so every Jade section can be traced back to Alfred.

## Acceptance criteria
- No Jade core topic duplicates a mature Alfred lesson unnecessarily.
- Every retained Alfred section still makes sense in the new order.
- No future Alfred prerequisite is silently assumed.
- Apply-Now Core can be completed without waiting for full CETa breadth.
- Embedded Bridge still connects cleanly to Alfred Weeks 16–18 and 24–29.
- Required media is contextual, not dumped into a library without lesson placement.
- Labs produce artifacts that can support a job interview or portfolio.
