## Functional repairs implemented
- Page views no longer create completion.
- Each teaching section requires explicit completion.
- Sequential Continue button is gated by completion.
- Final lesson page requires section completion + all quiz questions correct + complete practical evidence before sequential advance.
- Practical evidence requires every field plus learner attestation.
- Study competency checkboxes persist.
- Progress readiness requires every core teaching section, quiz, and practical.
- Progress export/import is available as JSON.
- v0.1 completion flags do not migrate because the old completion model was invalid; resume/focus history can migrate.
- Resource placeholders were replaced by linked resources.
- Service-worker cache cleanup and update lifecycle were improved.
- Global focus-visible accessibility treatment added.
- Active brand assets converted from large PNG files to WebP.

A Chromium runtime attempt was made in the internal container, but local HTTP/file navigation is blocked by the environment administrator. Therefore this build was validated with JavaScript syntax checks, cross-file reference checks, data-contract checks, and static DOM-selector checks rather than a rendered browser session.
